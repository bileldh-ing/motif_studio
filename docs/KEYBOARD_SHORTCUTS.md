# Keyboard shortcuts

| Keys | Action |
|---|---|
| Space | Play / pause |
| ← / → (Shift: 1 s) | Step frames |
| Home / End | Start / end |
| S, Ctrl/⌘+B | Split selected (or everything under the playhead) |
| Delete / Backspace | Ripple delete |
| Shift+Delete | Delete leaving a gap |
| Ctrl/⌘+D | Duplicate |
| Ctrl/⌘+Z, Ctrl/⌘+Shift+Z, Ctrl+Y | Undo / redo |
| Ctrl/⌘+S | Save |
| Ctrl/⌘+I | Import |
| Ctrl/⌘+E | Export |
| I / O | In / out point |
| M | Marker |
| + / − | Zoom |
| Esc | Cancel drag / deselect |
| ? or Ctrl/⌘+/ | Shortcut list |

Shortcuts are ignored while typing in text fields.
